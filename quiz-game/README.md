# 🎮 Python Quiz Game

A beginner-friendly command-line quiz game built with Python.

The game asks multiple-choice questions, randomizes the questions and answer options, checks the player's answers, calculates the final score, and allows the player to play again.

## Features

- 10 multiple-choice questions
- Randomized question order
- Randomized answer options
- Input validation
- Instant answer feedback
- Automatic score calculation
- Percentage calculation
- Performance message
- Play-again option
- Simple command-line interface
