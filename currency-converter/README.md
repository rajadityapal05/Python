\# Currency Converter



A simple beginner-friendly Python application that converts Indian Rupees (INR) into USD, EUR, and GBP.



\## Features



\- INR to USD conversion

\- INR to EUR conversion

\- INR to GBP conversion

\- Fixed exchange rates

\- Input validation

\- Multiple conversions

\- Simple terminal interface



\## Technologies



\- Python

\- Functions

\- Dictionaries

\- Loops

\- Conditional statements

\- Exception handling



\## How to Run



Open PowerShell inside the project folder and run:



```bash

python currency\_converter.py
